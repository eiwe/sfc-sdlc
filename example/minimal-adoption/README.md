# Minimal adoption example

This is what a repo looks like after adopting the Spec-First Collaborative SDLC.

## Files added

```
AGENTS.md
HANDOFF.md
CHANGELOG.md
TESTING.md
docs/decisions/
docs/prd/
.github/pull_request_template.md
```

## First session

1. Read `HANDOFF.md`.
2. Read `AGENTS.md`.
3. Pick up the top priority from `HANDOFF.md`.
4. If the priority needs a PRD or ADR, write it first.
5. Implement, test, open PR, update `CHANGELOG.md` and `HANDOFF.md`.
